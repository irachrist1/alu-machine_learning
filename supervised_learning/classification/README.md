# Classification

Binary and multiclass classification implemented from scratch using NumPy.

## Tasks

| File | Description |
|------|-------------|
| `0-neuron.py` | Single neuron with public attributes |
| `1-neuron.py` | Single neuron with private attributes and getters |
| `2-neuron.py` | Forward propagation (sigmoid) |
| `3-neuron.py` | Logistic regression cost |
| `4-neuron.py` | Evaluate predictions |
| `5-neuron.py` | Gradient descent |
| `6-neuron.py` | Training loop |
| `7-neuron.py` | Training with verbose output and cost graph |
| `8-neural_network.py` | One hidden layer network, public attributes |
| `9-neural_network.py` | One hidden layer network, private attributes |
| `10-neural_network.py` | Forward propagation |
| `11-neural_network.py` | Cost calculation |
| `12-neural_network.py` | Evaluate predictions |
| `13-neural_network.py` | Gradient descent |
| `14-neural_network.py` | Training loop |
| `15-neural_network.py` | Training with verbose output and cost graph |
| `16-deep_neural_network.py` | Deep network with He initialization, public attrs |
| `17-deep_neural_network.py` | Deep network, private attributes |
| `18-deep_neural_network.py` | Forward propagation with cache |
| `19-deep_neural_network.py` | Cost calculation |
| `20-deep_neural_network.py` | Evaluate predictions |
| `21-deep_neural_network.py` | Gradient descent |
| `22-deep_neural_network.py` | Training loop |
| `23-deep_neural_network.py` | Training with verbose output and cost graph |
| `24-one_hot_encode.py` | One-hot encoding |
| `25-one_hot_decode.py` | One-hot decoding |
| `26-deep_neural_network.py` | Save/load with pickle |
| `27-deep_neural_network.py` | Multiclass with softmax output |
| `28-deep_neural_network.py` | Configurable sigmoid/tanh activation |

## Requirements

- Python 3.5
- NumPy 1.15
- pycodestyle 2.4

## Data

Datasets (`Binary_Train.npz`, `Binary_Dev.npz`, `MNIST.npz`) should be placed
in a `data/` directory one level above this folder.
