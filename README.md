# alu-machine_learning

ALU machine learning coursework — math foundations and ML exercises in Python.

## The problem

You're learning linear algebra, calculus, and ML concepts at ALU. Each exercise needs structured submissions that pass automated checkers.

This repo holds those exercises — not a product, not a library.

## What it does

`math/` folders for linear algebra, calculus, and plotting. Supervised and unsupervised ML exercise sets with checker-compatible one-file-per-concept outputs.

## Install

```bash
git clone https://github.com/irachrist1/alu-machine_learning.git
python3 -m venv venv && source venv/bin/activate
pip install numpy matplotlib
# Run exercises per folder README
```

## How it works

- **One file per concept.** ALU pattern (`0-slice_me_up.py`, etc.) — each file teaches one idea in isolation.
- **Checker-compatible outputs.** Formatted for ALU automated grading — follow each exercise's expected print format.
- **Math before ML.** Linear algebra and calculus folders precede supervised/unsupervised work — curriculum order preserved in directory structure.
