# Advanced Linear Algebra

This project covers advanced linear algebra concepts including:

- Determinants
- Minors
- Cofactors
- Adjugate matrices
- Matrix inverses
- Eigenvalues and eigenvectors
- Matrix definiteness

## Learning Objectives

- Understanding determinant calculation
- Computing minors, cofactors, and adjugate matrices
- Calculating matrix inverses
- Determining eigenvalues and eigenvectors
- Identifying matrix definiteness (positive/negative definite, semi-definite, indefinite)

## Requirements

- Python 3.5
- NumPy 1.15
- pycodestyle 2.5

## Tasks

0. **Determinant** - Calculate the determinant of a matrix
1. **Minor** - Calculate the minor matrix
2. **Cofactor** - Calculate the cofactor matrix
3. **Adjugate** - Calculate the adjugate matrix
4. **Inverse** - Calculate the inverse of a matrix
5. **Definiteness** - Determine the definiteness of a matrix
